# Short Shifter

## Short description
Hide YouTube Shorts behind a bouncing, winking poo.

## Description
Short Shifter gives you a simple switch for portrait-format YouTube Shorts. Turn **Shorts visible** off and approximately 9:16 media is covered locally with a dark placeholder containing a bouncing, periodically winking 💩. Turn it back on and YouTube returns to normal.

- ±5% aspect-ratio tolerance
- Dynamic YouTube page support
- Local preference storage
- No analytics or tracking
- No external runtime service

All detection happens locally in the browser.
